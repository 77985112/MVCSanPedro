# Catálogo territorial de Bolivia

`ubicaciones_bolivia.json` se generó a partir de `municipios_bolivia_2024.csv`, publicado por Lab TecnoSocial con nombres y códigos del INE/CPV-2024.

Fuente: https://github.com/lab-tecnosocial/municipios-bolivia-2024
Licencia del conjunto derivado: CC BY 4.0.

Para este formulario se excluyeron las tres filas cuyo nombre comienza con `TIOC-`, porque la interfaz solicitada utiliza únicamente la etiqueta «Municipio». Se conservan 340 registros municipales, agrupados por los 9 departamentos y sus provincias. La interfaz permite ingreso manual cuando el lugar requerido no aparece.
